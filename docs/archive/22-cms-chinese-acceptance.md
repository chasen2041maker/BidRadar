# 22｜中文优先的 CMS 选型与薄流程验收

2026-09-12｜用户已明确中文开发/使用体验优先。选型仍待运行验证；本次只设计验收，不安装 CMS、不测试真实浏览器或 Redis。

## 1. 目前判断

暂保留 Strapi 5 Community Edition 为首选验证对象，不因上一轮已推荐就跳过中文门槛。2026-09-12 官方发布 API 返回 v5.53.0（发布于 2026-09-09）；本轮读取该版本后台 `zh-Hans.json`，确有简体中文登录、内容管理和错误提示条目。[S1][S2]

官方支持通过 `src/admin/app` 的 locales/translations 配置语言及覆盖翻译。[S3] 这只证明具备适配基础，不证明所有插件/报错/输入法和搜索都适合中文。不得把缺少翻译的核心流程留给使用者用浏览器翻译，也不直接改 node_modules 来保留补丁。

Payload 为可行备选，其官方文档区分管理界面的 i18n 和内容多语言，并说明后台基于 Next.js/React。[S4][S5] 若 Strapi 需要大幅补丁、核心中文链路不能通过或费用/资源不可接受，再比较备选；不因为“有中文包”就武断宣称某个项目中文最好，不默认换核心 Python 服务。

社区版/付费功能边界仍按 19：不要把企业版审计、内容历史或未知插件当成免费现成能力。上线前重新锁定版本并检查安全、许可和依赖；v5.53.0 只是本次审阅基线，不是永久生产版本。

## 2. 三件事分别验收

后台中文化是菜单、表单、按钮和错误消息；中文内容是能正确编辑/存储/查询正文；内容多语言是同一内容存在多语种版本。三者不是一回事。首版主要维护中文帮助/常见问题/站内公告，不因此承诺海外招标资料已翻译理解或全球语种都支持。

业务文档、注释中解释性文字、验收和用户文案优先中文；代码标识符、API 键、状态枚举与错误码保持一致的英文机器标识，展示层作中文映射，不把已有字段随意改成中文键。

## 3. 中文与权限测试门槛

| ID | 输入/操作 | 必须观察到的结果 |
| --- | --- | --- |
| ZH01 | 中文用户首次登录、切换语言、退出重登 | 关键菜单和工作流为简体中文，偏好不丢失；不把普通用户放进平台后台 |
| ZH02 | 拼音输入法连续输入、选词、回车、粘贴中文 | 组合输入不被截断、不误提交表单，长标题/全角标点/中英混排保存后保持一致 |
| ZH03 | 文章“知识库使用指南”，搜索“知识库” | 列表能定位目标且分页稳定；子串查询通过不宣称已实现中文分词或全语义搜索 |
| ZH04 | 必填为空、重复唯一字段、无权、登录过期、请求失败 | 中文说明可理解且能区分原因；机器错误码稳定，不展示私有堆栈或他人信息 |
| ZH05 | 中文长标题、图片文件名、替代文本和富文本 | 无乱码/关键按钮遮挡，媒体权限正确；危险富文本和不允许的文件类型被处理 |
| ZH06 | 草稿预览、发布、修改、撤下；匿名直接访问 | 草稿仅授权可见，撤下不可从公开 API/缓存继续得到正文；保留操作与版本证据 |
| ZH07 | 编辑员访问成员管理、其他企业资料或任务重试 | 服务端拒绝越界；隐藏菜单不是唯一权限手段 |
| ZH08 | 浏览器/API 请求不同语言，同一内容不同版本 | 不串语言和版本；展示时间标明时区，UTC 原始时间与显示规则分开 |

先约定测试系统/浏览器/版本和输入法；至少在负责人实际使用的中文桌面环境验证一次，并覆盖项目明确支持的浏览器，不凭一张截图宣布跨浏览器兼容。关键流程必须通过；非关键回退文本登记问题和影响。截图、录屏、请求、数据库结果与提交版本关联，不能预填通过状态。

## 4. 下一条薄流程：中文帮助文章与缓存

编辑员写中文草稿 → 发布 → 工作台公开读取 → 第二次读取命中缓存 → 更新内容生成新发布版本 → 撤下后直接链接和公开 API 都拒绝正文。

实施前先确定稳定内容 ID、语言、状态、发布时间/时区、版本、预览鉴权、API 字段/空值/错误与重试规则；不在选型文档里猜 Strapi 实际接口。草稿状态、发布快照、必要操作记录及独立数据库由内容组件拥有，业务服务不跨库读取。

先保存事实，再通过可重试记录失效；键含环境、内容 ID、语言和版本。撤下须检查当前发布状态，不能只等 TTL。检测失效失败、乱序、旧请求晚回填、并发热点、Redis 不可用和重复发布；记录实际回源、命中、错误和资源，禁止预设虚假提升比例。

CMS 数据库、Node 进程、缓存和备份计入原月预算。该薄流程可先在获授权的隔离本地环境验证，不是先完成整个运营平台，也不阻塞 R0/R1 招标研究路线。尚未获得的安装、外部访问或计费权限需在实施任务明确，不通过写验收文档自动取得。
