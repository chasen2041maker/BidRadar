# 13｜按业务缺口选来源，保留真实清洗证据 v0.3

**Proposed｜2026-09-11。以下来源观察继承先前记录，本轮未重新访问、未抓取或建立回归数据集。**

## 1. 来源数量不再是阶段门槛

首个业务链建议一个主来源；第二及更多来源只补材料、覆盖、状态更新或重要格式缺口。取消原 R0 两种输入前置、R1 四源、R3 六源及三活跃来源配额；完整 v1 保留真实网页与文件清洗，不要求在 Agent 前一次完成。

同平台 API/XML/HTML/PDF 仍算一个独立来源；转载/翻译不是新采购程序；香港多个页面不代表多个国家。历史授标/取消可作关联与负例，不计入当前机会清单。全球目录是后备资料，不是开发清单。

## 3. 扩源前的五个问题

当前哪项用户工作做不成？是缺少项目、原文、附件、更正还是语言能力？当前来源的公开材料能否补齐？新来源是否允许访问/保存/分析及展示？新增后的维护、费用、标签和回归成本是多少？

这些写入决策记录。新增一个国家不是独立的业务理由；为了测试一个 HTML 解析问题，不必先运营整个网站连接器。

## 5. 已记录的真实语义观察

### Q-OBS-01：Open 不等于仍在招标

先前阅读规划署页面发现，已授标和取消的记录也会在 Tender Procedure 列出现 Open。它描述采购方式，不可直接映射当前状态。[S16](12-source-register.md#s16)

验收提案：保留所属分节、表头、行和定位；授标/取消记录不进活跃列表。这是语义陷阱，不是断言来源写错。

### Q-OBS-02：同块不同截止日期

先前阅读医务卫生局页面，资料征询截止、交流活动登记截止以及关闭说明可能同处信息块。[S15](12-source-register.md#s15)

验收提案：日期必须有类型、作用范围和原始表达；登记日期不替代提交日期，PDF/Word 图标不证明附件仍可下载。具体历史例子和读取边界见16。

### Q-OBS-03：动态模板不是零条数据

BOAMP 入口先前只取得模板占位与部分标识，未完整取得记录。[S17](12-source-register.md#s17)

验收提案：区分未渲染/未提取、获取失败和真正空结果，不让水位把失败窗口跳过去。

这三项是历史页面观察，尚无已冻结样本、实现或通过的测试。后续按许可取得可追查原件，不能以本说明代替运行证据。

## 6. 清洗类别与业务后果

| 类别 | 需要保留 | 防止的错误 |
| --- | --- | --- |
| 缺失/空值 | 原值、缺失原因、未知和处理阶段 | 补零、编资格、猜时区 |
| 重复/转载/语言 | 源关系、哈希、业务身份依据 | 同一商机重复推荐，或去掉必要来源 |
| 更正/晚到 | 源版本、生效关系和影响标段 | 旧公告回退新状态或全行覆盖 |
| 金额 | 币种、量级、类型、税/期间与标段 | 总价当每标段预算、不同币种直接比 |
| 文本 | 标题、表头、否定、脚注和定位 | 正文清洗后丢关键限制 |
| 编码/模式 | CSV 引号换行/BOM、XML 命名空间、规则版本 | 静默忽略乱码或按列号猜字段 |
| PDF/Word | 页码、阅读顺序、原件、文本可得性 | 把扫描件当可读全文，或运行宏 |
| 来源冲突 | 各方观察、引用和关系状态 | 模型选更有利的一份当唯一事实 |

这些是待测类别，不表示每源已发现全部问题。没有自然例子可做注入测试，但必须单列。

## 7. 台账和统计

natural_observation、parser_defect、injected_case、amplified_replay 分开。原件正常而解析丢字段属于实现错误；模型建议不等于人工标签。

每案例记录 ID、类型、源标识、原件哈希、定位、原值、预期、规则/parser版本、实际结果、影响、复核与回放方式。一个规则修改多记录时保留误修检查。

每源/格式报告互斥输入结果、不可获取与排除原因。自然异常比例不混入人工注入和负载扩增；没有足够样本只报告观察，不强报百分比。

## 8. 重处理和关联撤销

修规则只重处理受影响原件，生成新 document_version 并传播目录修订；旧报告保持历史快照，当前视图标待复核。误合并由 catalog 发布关联修订，研究/跟踪重新核查，不能隐藏旧决定。

撤回和删除的 tombstone 参与索引/事件重放，避免恢复时复活已撤回数据。备份删除按明确保留策略说明，不能称即时全部清除。

## 9. 真实网页/文件完成标准

在完整 v1 收口前，至少一条真实 HTML 路径和一条实际文件输入，在获准范围内完成获取、原件留存、结构解析、隔离、版本化规范结果、引用及错误回归。可同一来源提供，也可为当前产品补一个来源；不要求独立站点数量。

允许核心研究版本先用已具备证据的一种输入，后续补齐上述路径。API 数据自行转 HTML 不能算网页采集；只抓标题让模型猜不算清洗。扫描/OCR 不是硬门槛，有实际需求再审成本和质量。
