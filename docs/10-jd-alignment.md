## 3. 深度优先于技术拼盘

Python 后端为主；TypeScript 用于工作台，不代替 Node 深度。六服务不等于六模型；大量容器不等于分布式正确性。MCP、Kafka、服务网格和模型训练需要独立业务理由，不因面试词汇直接加入。

训练/推理优化、数年生产规模经验、英语或任职年限仍需另外证明。公开数据不等于真实客户成果，压测虚拟用户不等于活跃用户。
