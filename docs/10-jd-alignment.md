## 3. 不为 JD 做技术拼盘

共同工程能力优先，不取所有岗位技术关键词的并集。Python 为主线；TypeScript 用于工作台，不声称等价于 Node 后端熟练度。Kubernetes 用实际部署与故障实验说明能力，不上来建设通用平台。

MCP 只有在明确外部系统需要以协议访问本项目工具时再审，不能为简历词汇暴露多余接口。多个 Agent、模型训练、全套云平台、消息中间件大全都不是首版必须。

## 4. 明确未覆盖项

本项目不能代替模型预训练/微调/推理优化、深度 Node/Java/Go 工程经验、数年大规模生产实践、英语水平或雇主规定的年限。受控部署不自动等于长期线上运维。

拿不到原始 JD 的要求暂不作为强制验收。投递前重新核验地点、签约主体、岗位职责、经验范围与报酬条件，不能仅按公司品牌或岗位名决定匹配。
