## 数据流与失败边界

未来的服务端须先认证当前人、读取其当前成员关系、从资源拥有者查出归属/分类，再调用本函数。True仅表示这两种动作的基础成员/角色条件通过；仍需输入资料授权、模型外发许可、预算和实际资源校验。纯函数本身不做这些I/O。

管理员也不能跨公司；只读成员可看普通报告但不可请求分析。受限资料及受限派生报告暂时全部拒绝，即使管理员也不走普通共享路径。未知角色/动作/类型和空标识拒绝；不做宽松的字符串转布尔授权。实际撤权/缓存/数据库攻击实验尚未执行。
