# 0009. 文档精简为人话版本

- 状态：已采纳
- 日期：2026-10-12

## 背景

到 2026-10-01，项目有 34 篇专题文档加学习笔记，约 44 万字节，和业务代码一个量级。文档写得高度压缩，大量"X 不等于 Y"和代号，人很难读；状态文档还经常过期。另有一套脚本和 CI 专门维护这些交接文档的格式。

## 决定

- 只保留少量文档：README、架构说明、研究 Agent、数据模型、开发指南、路线图、决策记录、v2 蓝图。
- 旧文档、学习笔记、交接状态文档原样移到 `docs/archive/`，不再更新。
- 维护交接文档的脚本、测试和 CI 一并归档；CI 改为只跑测试和格式检查。
- 写作规则见 [开发指南](../dev-guide.md)：先说结论，一句话一件事，优先用肯定句，不用代号。
- 代码注释同样改成人话，写"为什么"，不复述代码。

## 为什么

文档是写给人看的。读不懂的文档等于没有，过期的文档比没有更糟。

## 代价

- 一些过程细节只能去 `docs/archive/` 或 PR 里找。
- 自动检查交接文档格式的机制没有了，文档是否同步要靠提交时自觉检查。
