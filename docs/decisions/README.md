## 模板

```markdown
# 编号. 标题

- 状态：提议 / 已采纳 / 已被 XXXX 取代
- 日期：YYYY-MM-DD

## 背景
遇到了什么问题，有哪些约束。

## 决定
具体决定了什么。

## 为什么
考虑过哪些方案，为什么选这个。

## 代价
这个决定带来的限制、风险和以后要付出的成本。
```
