# 0001. 首批市场和目标用户

- 状态：已采纳
- 日期：2026-09-12

## 背景

招标信息覆盖面极广（政府、国企、全球），一开始就想全覆盖，会把精力耗在采集上。

## 决定

- 首批只做**中国境内公开的软件开发、业务系统、AI 应用**类采购项目，中文优先，不限城市。
- 用户是**想承接这类项目的软件公司和 AI 服务团队**，远程团队也是目标用户。
- 核心流程：确认企业档案 → 找到相关项目 → 查看原文和材料缺口 → 带引用的条件分析 → 同项目追问 → 人工决定跟进或放弃。

## 为什么

先把一个窄场景做深：能讲清楚一个项目"要什么、我们有没有、还缺什么"，比覆盖很多来源更有价值。

## 代价

- 来源少，项目数量有限。
- 还没有真实的试用公司，产品价值没有经过用户验证。
