# BidRadar — 招标商机分析与跟踪 Agent

> 帮软件与 AI 服务团队发现值得进一步核查的公开招标项目，看懂要求，并跟踪变化。
>
> An evidence-based agent for discovering, assessing, and tracking public tender opportunities for software and AI service teams.

**当前阶段：DESIGN_REVIEW（设计审核），不是开发中或已上线。**

本仓库目前只交付计划与设计文档。产品方向已经确定，但架构、数据模型、技术选型、验收阈值均需审核；提交文档不代表项目负责人批准实施。没有业务代码、可运行服务、真实数据接入成果、评测成绩或生产部署。

## 计划中的业务闭环

公开公告 → 保存原始版本 → 清洗与关联项目/标段 → 匹配企业能力 → 展示要求与证据 → 人工决定是否跟进 → 跟踪后续变化。

系统提供辅助筛选，不保证投标资格或中标，不自动提交投标，不自动联系采购方。**资料缺失不等于不满足条件，技术匹配也不等于具备参与资格。**

## 协作原则

项目负责人亲自实现核心代码、接入真实数据、调试和验证；AI 协助方案设计、解释、代码审查与文档整理，不代替个人掌握全链路。后续协作者先读 [AGENTS.md](AGENTS.md)。

当前不提供安装命令、演示地址或完成度百分比。先审核，再经明确授权进行有限验证，随后才开始业务实现。
